🧰 这是浏览器演示版

这是一份纯前端 H5 演示，用来预览小程序上线后的样子。所有功能都接了 mock 数据，不需要云开发。

🎯 你可以试这些交互

  • 点底部 5 个 tab 切换页面
  • 在首页点活动右侧「→ 导航」按钮 —— 会真的跳转到高德地图
  • 在上传页面点大块区域，模拟上传一份攻略，会自动跑 AI 解析进度条
  • 在闹钟页面点「+」新增闹钟；点闹钟可模拟触发

📌 区别于正式版

  • ✅ UI 完全一致：手机壳 + 状态栏 + TabBar + 卡片样式
  • ✅ 真实跳转：高德地图按钮是真实链接，能在浏览器打开高德 web 版
  • 🔸 Mock 数据：广西 7 天游（来自你提供的 docx 攻略）
  • 🔸 无云函数：所有 AI 解析/数据库读写都是前端假数据
  • 🔸 无订阅消息：闹钟触发只弹窗，不会真推送
